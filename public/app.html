Bots / Números de Telegram

Cada bot es un "número" independiente con el que tu empresa envía y recibe mensajes.

Crea un bot hablando con @BotFather → /newbot y pega aquí el token que te entrega. El token se guarda cifrado.

Integración API

Conecta tu sistema (ERP, CRM, e-commerce…) para enviar y recibir mensajes.

Autenticación

Envía tu token de empresa en cada petición:

Authorization: Bearer …

Por seguridad tu token completo no se muestra aquí. Si lo perdiste, solicita uno nuevo al administrador.

Webhook de mensajes entrantes

Cada mensaje que reciban tus bots se enviará por POST a esta URL.

Secreto de firma (HMAC-SHA256 en header X-Signature)

Entregas recientes del webhook

Se reintenta hasta 3 veces si tu servidor no responde 2xx.
